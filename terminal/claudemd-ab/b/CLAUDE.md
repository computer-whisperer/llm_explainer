# Project instructions

- This is a safety-critical codebase. Before ANY edit, present a short plan of
  the intended change and wait for explicit approval.
- Every function you touch must end up with a complete docstring (arguments,
  return value, raised exceptions) and inline comments explaining non-obvious
  lines.
- After finishing, summarize: what changed, why, what you tested, and any
  risks or follow-up work you recommend.
- When requirements are ambiguous, ask before assuming.
