The model never sees words — it sees tokens

Everything in and out of the model is a sequence of integers from a fixed 262k-entry vocabulary. Type anything; this is the real gemma-4 tokenizer.

The whole model does one thing: predict the next token

Given everything so far, the model outputs a probability for every token in the vocabulary. One gets picked, appended, and it runs again. That loop is the entire product.

The document never goes to the model alone — framing tokens wrap it (chat models fall apart without them). The instruction is part of the context too: edit it and the same document continues differently.
